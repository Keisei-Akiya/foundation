# ADR 0001: Wiki 検索の設計を決める

状態: 承認済み。

## 背景

Issue #17 の Wiki 検索では、Jev に渡す入力、ドメイン情報の出所、`domains:` が無いページの扱い、ドメイン採点の方式、ページスコアの計算を決める必要がある。

既存の試作は Python の検索スクリプトを `foundation decide` から呼び出す構成を前提としていた。

親 spec では検索機能を Rust の `foundation wiki-search` として実装し、Jev 通信には `foundation decide` の内部処理を共有する方針を承認している。

## 決定

### 1. 質問を `input` に置き、ページのタイトルと要約を項目ごとの `instructions` に置く

会話の文脈を補って書き直した質問を Jev の `input` に置き、ページごとのタイトルと要約を各項目の `instructions` に置く。

同じ質問を各ページの評価に使えるため、ページごとに質問を複製する構成を避けられる。

Jev に渡すページ情報はタイトルと要約に限り、ページ本文は送らない。

### 2. ドメイン名と説明は Wiki の `SCHEMA.md` から読む

ドメイン名と説明は Wiki の `SCHEMA.md` から読み取り、スキルや検索機能側に複製しない。

Wiki の分類定義を唯一の説明元とすることで、分類が更新されたときに複製が古くなることを避ける。

### 3. `domains:` が無いページをページ採点の候補に常に加える

1 段目で残ったドメインに属するページに加え、`domains:` が無いページも常にページ採点の候補に加える。

ドメイン情報が無いページはどのドメインにも対応づけられないため、除外すると関連する背景情報を見落とす可能性がある。

### 4. ドメインを独立した Yes / No で採点し、Yes の確率を使う

各ドメインについて、「この質問に答えるのに、このドメインのページが必要か」を独立した Yes / No で尋ね、Yes の確率をドメインの確率とする。

確率はドメイン間で合計 1 に正規化せず、「該当なし」は選択肢にしない。

複数のドメインにまたがる質問を複数の候補として残せるため、単一選択の分類より見落としを抑えられる。

「該当なし」を選択肢にすると、質問に関係なく選ばれる疑似ドメインがほかの候補を押しのけるおそれがある。

閾値以上のドメインをすべて残し、どのドメインも閾値に届かない場合は、確率が最も高い 1 ドメインを残す。

ドメインの閾値と最大数は、ページの閾値と最大件数から独立した実行時引数とする。

初期値は評価で決めた値ではなく、見落としを抑えるための仮の値とする。

### 5. ページの関連スコアに `P(low) + P(high)` を使う

ページ採点では、ページの関連スコアを `P(low) + P(high)` とする。

直接の答えだけでなく背景として役立つページも拾うという、見落としを減らす優先事項に沿うためである。

ページの閾値と最大件数は実行時引数で指定し、初期値は評価で決めた値ではなく仮の値とする。

## 実装方針

検索機能は Python スクリプトではなく、Rust の `foundation wiki-search` サブコマンドとして実装する。

既存の `foundation` バイナリをスキルから再利用でき、検索のための別 Python 実行環境や偽の `foundation` コマンドを必要としない。

Jev 通信には `foundation decide` の既存内部処理を共有し、認証とエラー処理の重複を避ける。

`foundation decide` は Jev への汎用依頼専用のままとし、Wiki 固有の判断を含めない。

既存 Python 版は仕様と振る舞いを確認する参考にとどめ、Rust のテストは親 spec の受け入れ基準を正本として作る。

Python の検索スクリプトとそのテストの削除は、Rust 版への置き換え後に行う後続チケットの範囲とする。

## 用語と適用範囲

検索はドメイン採点、ページ採点の順に行う。

ドメイン採点では、ドメインごとに独立した Yes の確率を求め、閾値以上のドメインを残す。

ページ採点では、残したドメインに属するページと `domains:` が無いページを候補とし、各ページのタイトルと要約を使って関連スコアを求める。

候補とは、その段階の採点対象として選ばれたドメインまたはページを指す。

閾値とは、ドメインまたはページを残すための関連確率の下限を指す。

どのドメインも閾値に届かないときは最高確率の 1 ドメインを残し、どのページも閾値に届かないときは最高スコアの 1 ページを返す。

閾値と最大数の初期値は仮の値であり、精度評価や閾値調整はこの決定に含めない。
