# Hook 共通状態ストア

共通ストアのルートは明示された `HERMES_HOME/plugin-data/foundation/` とする。
`HERMES_HOME` がない場合は `StateStore::from_env` がエラーを返し、実ユーザーのホームへフォールバックしない。
テストは一時ディレクトリを `StateStore::new` に渡す。

各状態系列は `<name>.jsonl` に UTF-8 の JSON オブジェクトを一行ずつ保存する。
`name` は ASCII 英数字、`_`、`-` のみで最大64 byteとし、セッションIDも別の検証関数でパストラバーサル文字を拒否する。
相対状態パスは通常のパス要素だけを許可する。

ディレクトリ権限を Unix では `0700`、データファイル権限を `0600` にする。
追加時は対象ファイルを排他ロックし、読み出し時は共有ロックを取る。
JSON一件と改行を一つのバッファとして追記し、協調する reader/writer は部分レコードを観測しない。
クラッシュで末尾行が壊れた場合、読み出しは不正な行だけを読み飛ばす。
読み出し時に JSONL ファイルを変更しない。
このストアは保持期間を強制しないため、各状態系列の所有者が保持・削除方針を定義する。

`<name>.enabled` は明示的なオプトインを表し、`<name>.disabled` があれば常に無効にする。
どちらもない場合は呼び出し元が渡す既定値を使う。

この変更では旧 `plugin-data/ecc-hooks/` のデータを移行せず、既存 hook の書き込み先も変更しない。
旧データの自動コピーや二重書きは行わず、後続の各 hook 移行時に読み込み互換性と切替時期を個別に決める。
この方針により、既存 JSONL を壊さず新しい hook から共通 API を利用できる。
